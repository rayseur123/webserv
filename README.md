Description:

Webserv is a basic HTTP server based on RFC 1945 (HTTP/1.0)  
The server handle HTTP method like GET, POST, DELETE and all CGI type (python, php...) 

Instructions:



Features List:

- Custom webserv.conf
- Handle HTTP/1.0
- Handle all type of Cgi
- Accept method: GET POST DELETE
